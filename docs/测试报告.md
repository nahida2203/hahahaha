## 4. 问题与修复记录

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 启动后登录必然失败（阻断） | YAML 加载使用 `/config.yaml` 绝对路径，未带 `base: '/funong-ai-create/'`，返回 404 | 改为 `${import.meta.env.BASE_URL}config.yaml` 拼接（[configLoader.ts](file:///j:/jqr/funong-ai-create/src/utils/configLoader.ts#L92)、[appDataLoader.ts](file:///j:/jqr/funong-ai-create/src/utils/appDataLoader.ts#L39)），回归验证通过 |
| js-yaml v5 无默认导出 | `import yaml from 'js-yaml'` 运行时报错 | 改为 `import { load as parseYaml } from 'js-yaml'` |
| 测试中 axios-retry 崩溃 | 假客户端缺少 `interceptors`/`defaults` | 测试改用 `vi.hoisted` + 含 interceptors 的最小实例 |
| 视频测试出现未处理拒绝 | 断言挂载晚于 fake timer 推进 | 先创建 assertion 再推进定时器 |
| 生成海报后 `net::ERR_BLOCKED_BY_ORB`（图片加载失败） | S3 签名 URL 无 CORS 头，隔离预览环境跨域加载被 ORB 拦截 | 图像接口改请求 `response_format: b64_json`，海报以 `data:image/jpeg;base64` 同源渲染，不发起跨域请求（[contentGenerator.ts](file:///j:/jqr/funong-ai-create/src/utils/contentGenerator.ts)） |
| 视频生成报 `video reference must have type "image"` | 图生视频参考图 `image.type` 误传 `image_url`，中转站校验不通过 | 修正为 `image: { url, type: 'image' }`（[grokVideo.ts](file:///j:/jqr/funong-ai-create/src/api/grokVideo.ts)） |
| 视频参考图提交 `data:text/plain` 被拒（`image data URI requires an image MIME type`） | 素材 URL 为 `/photos/*.webp` 缺少 base 前缀，fetch 到 404 错误页（text/plain）被误转成 data URI | ①数据层统一补全 `BASE_URL` 前缀（[appDataLoader.ts](file:///j:/jqr/funong-ai-create/src/utils/appDataLoader.ts)）；②参考图转换校验 `response.ok` 与图片 MIME，失败即放弃参考图降级文本生视频（[contentGenerator.ts](file:///j:/jqr/funong-ai-create/src/utils/contentGenerator.ts)） |
| 视频模型统一返回 `Video generation is not enabled for this group` | 中转站对当前 API Key 分组未开通视频生成权限（平台侧配置） | 前端将权限类错误翻译为中文提示并降级；需平台侧开通权限（见 §3.4） |
