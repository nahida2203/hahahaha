# 福农AI创 · 配置说明

> 所有配置均存放于 `public/` 下的 YAML 文件，**代码中禁止硬编码业务配置**。
> 敏感字段一律使用 AES-256 密文（密钥见 `.env`）。

## 1. 环境变量 `.env`

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `VITE_CRYPTO_KEY` | 是 | AES-256 解密密钥，用于解密 YAML 中的密文字段。生产环境务必替换为强随机密钥。 |

参考 [.env.example](../.env.example)。

## 2. `public/config.yaml`

### 2.1 `settings`（业务运行参数）

```yaml
settings:
  quota:
    initial_balance: 688        # 初始可用额度（点）
    cost_per_version: 100       # 单渠道文案版本消耗（点）
    media_cost_image: 20        # 图片生成流程消耗（点）
    media_cost_video: 40        # 视频生成流程消耗（点）
  storage:
    total_bytes: 524288000      # 素材存储总容量（字节，500MB）
    sample_asset_size_bytes: 2097152  # 内置示例图按固定大小计入存储（字节）
```

### 2.2 `ai_models.grok_image`（图像生成模型）

> 当前经中转站 `https://sub2api.tegical.com` 调用，模型名保持 `grok-imagine-image`。

```yaml
ai_models:
  grok_image:
    endpoint: "https://sub2api.tegical.com/v1/images/generations"
    model: "grok-imagine-image"
    api_key_encrypted: "<AES-256 密文>"   # 明文 Key 由 VITE_CRYPTO_KEY 解密
    timeout_ms: 120000          # 请求超时（毫秒）
    max_retries: 3              # 最大重试次数
    retry_delay_ms: 500         # 首次重试延迟（指数退避基准，毫秒）
    enabled: true               # 是否启用真实模型
    fallback_to_local: true     # 失败后是否降级本地模拟
```

### 2.3 `ai_models.grok_video`（视频生成模型）

```yaml
ai_models:
  grok_video:
    endpoint: "https://sub2api.tegical.com/v1/videos/generations"
    poll_endpoint: "https://sub2api.tegical.com/v1/videos/{id}"  # 轮询地址，{id} 为 request_id 占位符
    model: "grok-imagine-video"
    api_key_encrypted: "<AES-256 密文>"
    timeout_ms: 120000
    max_retries: 3
    retry_delay_ms: 1000
    poll_interval_ms: 3000      # 任务状态轮询间隔（毫秒）
    poll_timeout_ms: 600000     # 单任务最长等待（毫秒）
    enabled: true
    fallback_to_local: true
```

> 若官方/网关地址变化，仅需修改 `endpoint` / `poll_endpoint`，无需改动代码。

## 3. `public/data/appData.yaml`（业务数据源）

| 节点 | 说明 |
| --- | --- |
| `channels` | 渠道字典（id/name/icon/description/copyStyle） |
| `template_scenes` / `template_styles` | 模板筛选的场景与风格枚举 |
| `templates` | 模板库（含提示词示例、封面、渠道范围） |
| `assets` | 内置示例素材（示例图上传用） |
| `demo_projects` | 演示创作记录种子数据 |
| `demo_accounts` | 演示账号（`password_encrypted` 为 AES-256 密文，加载时解密） |
| `creation_scenarios` | 快速创作场景（渠道/输出类型/提示词模板） |
| `output_types` | 输出类型选项（文案/长文/口播/海报/九宫格/分镜） |

> 新增渠道/模板/素材/场景只需修改该 YAML，无需改动代码。

## 4. 如何更新密文

场景：更换 API Key 或演示密码。

```bash
# 1. 用当前密钥加密新值
node scripts/encrypt-key.mjs "新的明文值" --key "你的VITE_CRYPTO_KEY"
# 2. 将输出密文替换到对应 *_encrypted 字段
# 3. 修改 .env 中的 VITE_CRYPTO_KEY 后，历史密文将无法解密，需同步重新加密所有字段
```

**注意**：更换 `VITE_CRYPTO_KEY` 会使所有既有密文失效，需一次性重新生成全部密文字段。

## 5. 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 启动报 `系统配置加载失败` | 确认 `config.yaml` 可访问、密文可由当前 `VITE_CRYPTO_KEY` 解密 |
| 登录失败 | 确认 `demo_accounts` 加载成功且 `password_encrypted` 与密钥匹配 |
| 生成结果均为"示例图" | 确认 `enabled: true`、Key 有效、网络可访问中转站；查看结果页警告条 |
| 视频生成长时间无结果 | 确认 `poll_timeout_ms` 足够，或查看控制台任务状态日志 |
| 视频模型报 `Video generation is not enabled for this group` | 中转站（sub2api.tegical.com）对当前 API Key 分组未开通视频生成权限，需在平台侧为该 Key 分组开通；代码已就绪，开通后无需改动即可生效 |
| 生成图片直接显示 `data:image/jpeg;base64` | 正常现象：海报改为 base64 同源渲染，避免跨域 ORB 拦截 |
